# 💖 Shayri App

**A Kotlin-Based Android Application for Discovering and Sharing Shayari**

Shayri App is an Android application that allows users to explore shayari through categories, browse collections of poetry, open individual shayari, and share their favourite lines with other applications.

Built with Kotlin and Android development tools, the project focuses on presenting expressive written content through a simple, accessible mobile experience.

## ✨ Features

* **Category-Based Browsing:** Explore shayari organised into different categories.
* **Shayari Collections:** Browse a list of shayari associated with a selected category.
* **Individual Shayari View:** Open and read a selected shayari on a dedicated screen.
* **Content Sharing:** Share shayari with other applications using the Android sharing interface.
* **Native Android Application:** Developed using Kotlin for the Android platform.
* **Simple Navigation:** Move between the opening screen, categories, collections, and individual shayari.

## 🏗️ How the App Works

The application provides a straightforward content-browsing and sharing experience.

1. **Open the application:** The user enters through the opening screen.
2. **Explore categories:** The user selects a category of interest.
3. **Browse shayari:** The application displays shayari associated with the selected category.
4. **Read individual content:** The user opens a shayari to view it separately.
5. **Share content:** The user opens Android's sharing interface to send the shayari to another supported application.

This flow demonstrates basic Android navigation, content organisation, and integration with the Android sharing system.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have:

* Android Studio installed.
* Android SDK compatible with the project.
* A JDK version compatible with the project's Gradle configuration.
* An Android emulator or physical Android device.

### 1. Clone the Repository

Open a terminal and execute:

```bash
git clone https://github.com/IamAyushLahiri/Shayri-App.git
```

### 2. Open the Project

Launch Android Studio and select **Open**.

Navigate to the cloned `Shayri-App` directory.

### 3. Sync Gradle

Allow Android Studio to synchronise Gradle and download the required dependencies.

### 4. Run the Application

Start an Android emulator or connect a physical Android device.

Click **Run** in Android Studio to build and launch the application.
